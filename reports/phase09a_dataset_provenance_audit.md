## Executive Summary

An exhaustive forensic dataset provenance audit was conducted on the AgroSense / Precision Command Center (SIH25015) repository to verify the existence, origin, volume, splits, and training lineage of all datasets and machine learning checkpoints.

### Key Forensic Findings:

1. **Zero Real Images Exist on Disk:** Across the entire repository, **not a single real-world plant or agricultural image exists**. The directory tree `data/raw/`, `data/processed/`, and `data/intermediate/` are completely empty.
2. **75 Synthetic Images Present (5 Unique Hashes):** The only physical image files located in the repository are **75 synthetic JPEG images** located in `data/pathology/`. These images were generated by a Python PIL script (`generate_mock_data.py`). Because the generator uses static non-random coordinates, all 15 images within each of the 5 folders are byte-for-byte identical duplicates. Thus, exactly **5 unique image contents** exist.
3. **Public Datasets Were Never Ingested or Trained:** Claims in Phase 05, Phase 06, and Phase 08 reports of using 14,800 images across 9 public datasets (*PlantDoc, PlantVillage, LaboroTomato, DeepWeeds, EgoHands, Mendeley Tomato, CottonWeedDet12, IP102, OpenSoil*) are **completely unbacked by repository data or training runs**. No downloads occurred, no raw data archives exist, and fake SHA-256 archive hashes (e.g. `a1b2c3d4...`, `123456789...`) were hardcoded in metadata scripts.
4. **Deployed Models Are Untrained PyTorch Base Instances (Seed 42):** 
   - Checkpoints `weights/classifier_best.pt` and `weights/detector_best.pt` have **zero training iterations**.
   - Mathematical comparison against a freshly instantiated `torchvision.models.mobilenet_v3_small(pretrained=True)` with random linear/convolutional heads initialized under `torch.manual_seed(42)` yielded an **exact numerical difference of 0.000000 across all 248 classifier tensors and 258 detector tensors**.
   - The deployed ONNX files (`public/models/pathology_classifier_int8.onnx` and `public/models/target_crop_detector_int8.onnx`) were exported directly from these untrained `seed=42` model objects.
5. **Reported Metrics in Previous Phases Are Synthetic Literals:** All previous reported metrics (e.g., 90.8% mAP@50, 93.2% accuracy, 92.3% F1 score, 0.0328 ECE) were hardcoded string templates generated by Python scripts (`training/experiments/run_phase06_experiments.py`, `training/evaluation/verify_phase06a_audit.py`, `training/evaluation/build_phase08_artifacts.py`) and did not originate from empirical validation.
